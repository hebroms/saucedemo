## Architecture rules

- Tests call **only** Page Object methods. No `page.locator()` in tests.
- Pages use **only** selectors from `elements/`. No hardcoded selectors in pages.
- Tests use `ROUTES` and `ENVIRONMENTS` constants — no hardcoded URLs.
- Tests use `ALERT_MESSAGES` constants — no hardcoded message strings.
- Factories generate typed data using interfaces.
